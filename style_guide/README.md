# Knowledge Foundation style source

The authoritative source is the user-supplied PDF:

`KOPIEREN VORHER_Knowledge_PPT_MASTER_Designvorlage_gesamt.pdf`

This repository does not commit the source PDF. `rules.json` records only rules
observed in that file. The original PowerPoint template was not available, so
coordinates and colors are reconstructed from the PDF and remain configurable.

The files in `assets/` are official raster marks extracted directly from the
supplied PDF. They must not be replaced with approximated shapes or typed text.
